Een extra dubbel geselecteerd juist antwoord werd bij alle drie geweigerd. Voor elk van de drie examens zijn 39/50 en 40/50 aan weerszijden van de slaaggrens gecontroleerd. De twee gerichte Vitest-bestanden leverden samen **12 geslaagd, 0 mislukt, 0 overgeslagen**. TypeScript en productiebuild slaagden. Lint leverde 0 fouten en 24 bestaande waarschuwingen op.
